# русская идея

https://spirin42.github.io/ideya/

Зритель открывает страницу и видит советский ковёр на стене. В ковёр можно
зазумливаться бесконечно, как во фрактал: под курсором, без конца. Ковёр при
этом искажается, но остаётся ковром — та же гамма, та же логика узора. Иногда
в глубине попадается целый вложенный ковёр.

Управление — только зум: колесо и щипок.

## Устройство

Одна страница без зависимостей: WebGL2, вся логика и обе картинки (ковёр и
обои) встроены в `index.html` как data-URI. Внешних файлов нет ни одного.

Счётчики скрыты, включаются через `?debug=1`.

Рядом лежат исходники этих двух картинок — `21_51_10.png` (ковёр) и
`21_50_52.png` (обои). Страница их не загружает: они уже внутри неё,
и лежат здесь только как оригиналы.
